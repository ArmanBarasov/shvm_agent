# shvm-coder

Агент чинит одну задачу из репозитория и выходит. Оценщик забирает `git diff`. Текст ответа модели не считается.

Модель на стенде всегда `deepseek-v4.1-flash`, thinking high. Свой ключ в репозиторий класть не нужно: стенд передаёт `OPENAI_BASE_URL`, `OPENAI_API_KEY` и `OPENAI_MODEL`.

## Как читать код

1. `agent.py` — аргументы и выбор профиля.
2. `harness/config.py` — конкурс и разработка. Это переключатель, не запасной провайдер.
3. `harness/loop.py` — фазы и лимиты. Здесь видно, что агент делает по шагам.
4. `harness/tools.py` — поиск, чтение, правка, repro и pytest.
5. `harness/guard.py` — какие файлы закрыты.
6. `harness/critic.py` — проверка diff перед выходом.
7. `harness/client.py` — запрос к модели и обрезанный ответ.
8. `harness/hints.py` — файлы из текста задачи, до первого вызова модели.
9. `harness/context.py` — короткая история диалога.

Промпты на английском: так модель устойчивее чинит английские issue. Комментарии в коде на русском.

## Что делает один прогон

Если в задаче есть путь или traceback, агент сразу читает эти файлы. Иначе один раз ищет по тексту ошибки.

Дальше он пишет скрипт воспроизведения вне репозитория, убеждается, что скрипт падает, правит исходник маленьким фрагментом и запускает скрипт снова. Рядом можно запустить один-два существующих тестовых файла, не весь набор.

Правка тестов и файлов сборки закрыта, пока issue не называет этот путь. Каталог `django/test` при этом не считается набором тестов: это код библиотеки.

За 20 секунд до конца новые гипотезы не начинаются. Если соседние pytest упали, правки откатываются. Неудачный скрипт воспроизведения правки не стирает: скрипт мог быть кривым.

## Профили

Конкурс, когда задан `OPENAI_BASE_URL` или `AGENT_PROFILE=contest`:

- только переменные `OPENAI_*`;
- модель обязана быть `deepseek-v4.1-flash`;
- выход 4096 токенов, тело запроса до 4 МиБ, 600 секунд;
- при ошибке шлюза запрос не уходит в другое место.

Разработка, даже если в окружении уже есть `OPENAI_BASE_URL`:

```powershell
$env:AGENT_PROFILE = "dev"
$env:OLLAMA_API_KEY = "ваш ключ"
python agent.py --task-file .\TASK.md --workspace .\repo
```

Явный `AGENT_PROFILE` побеждает автовыбор. Без него наличие `OPENAI_BASE_URL` включает конкурсный режим.

По умолчанию разработка тоже зовёт `deepseek-v4.1-flash` на `https://ollama.com/v1` и держит те же потолки, что стенд. `MATCH_LIMITS=0` поднимает потолок токенов для отладки промпта. Такой прогон балл не предсказывает. `DEV_REASONING=low` тоже только для отладки.

Пример переменных лежит в `.env.example`.

Локальный запуск:

```powershell
python agent.py --task-file путь\к\TASK.md --workspace путь\к\репозиторию
```

## Проверка без модели

Из корня репозитория:

```powershell
python -m unittest discover -s tests -v
```

Нужны Python 3.11+ и `pydantic`. Пакет `openai` нужен только для живого прогона.

```powershell
pip install -r requirements.txt
```
